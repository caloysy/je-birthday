BIRTHDAY.EXE repair package

Upload the contents of this ZIP to the ROOT of your GitHub je-birthday repository, preserving src/ and public/ folders. Existing artwork files in public/ are NOT included in this package: keep opening-screen.png, bedroom.png and birthday-song.mp3 in your existing public/ folder. If your images have different names, rename them to match. This version restores the opening, loading and bedroom screens. Bedroom clickable objects are not implemented yet.
